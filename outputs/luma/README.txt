LUMA - EXPENSE TRACKER SHOWCASE

Open luma-showcase.html in a browser. This single file works offline.
It uses the same presentation structure as the neighboring Open Studios
project: Presentation, All 17 screens, Try prototype, and Design system.

The reference-derived visual identity uses near-black, forest green,
luminous lime, light numerical typography, rounded shapes, and linked circles.
The Design system view includes the supplied reference and visual analysis.

INTERACTIVE WALKTHROUGH
1. Start at Welcome, then open Overview.
2. Add an expense. Spending totals, budgets, and insights recalculate.
3. Review category overruns and change monthly limits.
4. Search, recategorize, or remove an expense.
5. Add a monthly or annual subscription.
6. Pause tracking, change a reminder, or mark a service cancelled.
7. Inspect the renewal calendar and monthly summary.

Sample data: September 26, 2026, USD. Initial spending: $2,136.80.
Initial monthly budget: $2,400. Monthly subscription commitment: $62.46.
Data is stored only in this browser. Settings > Reset sample data restores it.
Restart returns to Welcome while preserving the user's changes.

No banks, payment services, or notification delivery are connected.
Tracking a cancellation does not cancel a real subscription.
New subscription records do not automatically post expense transactions.
Projection: spending so far / days elapsed * days in the month.
