OPEN STUDIOS - CLIENT SHOWCASE

Open open-studios-showcase.html in Edge, Chrome, Firefox, or Safari.
The file is self-contained and works offline; no setup is required.

Presentation: the design story and selected phone mockups.
All 17 screens: the complete core screen collection.
Try prototype: clickable and scrollable phone with search, saved artists,
map selection, filters, itinerary editing, events, preferences, and import.
Design system: colors, typography, component examples, and interaction notes.

open-studios-client-showcase.pdf is the printable 10-page screen document.
The interactive prototype is in the HTML companion, not in the PDF.

Client demo walkthrough:
1. Select Try prototype, then Explore studios.
2. Search for Maya, Ceramics, or North District.
3. Open an artist and save it with the bookmark.
4. Add another studio through Plan > Add a stop.
5. Reorder the itinerary and open the walking route.
6. Visit More > Import annual data and try the sample dataset.

Bookmarks, itinerary stops, and preferences stay in local browser storage.
Restart returns to the Welcome screen while preserving those choices.

All artist data, locations, dates, original artwork, and partner identities
are illustrative. The map is schematic. Directions, notifications, and
publishing are simulated. CSV can be parsed locally; XLSX is represented
in the product flow and requires CSV export in this offline prototype.

Interface icons: Lucide, ISC license. System typography uses device fonts.
